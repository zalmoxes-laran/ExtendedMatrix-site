Stratigraphic reliability (US sheet, Extended Matrix)

Affidabilità stratigrafica (scheda US, Extended Matrix) — an Extended Matrix vocabulary module.

An ordinal scale for the STRATIGRAPHIC RELIABILITY box of a stratigraphic unit sheet (ICCD US 2021), gathered from PyArchInit; aligned to the Extended Matrix certainty_level qualia.

Only the labels in the source language come from the sources. Labels marked with * (en, ro, el, es, pl, he, de) were drafted with the module and nobody has verified them yet: usable now, to be corrected after review.

Concepts
